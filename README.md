# B-LRP and LIME Explanations

B-LRP and LIME are two explanation methods that can be used on image data. In these two notebooks, both explanation methods can be ran on the MNIST dataset and a folder including example images, respectively.

All credit goes to the respective authors. Very slight adjustments were done by me.

The MNIST dataset can be found [here](http://yann.lecun.com/exdb/mnist/).

## Installation

Use the package manager [pip](https://pip.pypa.io/en/stable/) to install all requirements from the requirements.txt files. If you want to do so inside of a notebook, prepend "!".

```bash
pip install -r requirements.txt
```
